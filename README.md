# 问灵 Wenling

> 一个AI驱动的自动化访谈系统：研究者设计访谈框架，AI作为智能访谈者与受访者自然对话。

**当前版本**：v1.0.0 · 2026-05-08

---

## 这是什么

问灵是面向社会科学研究者的**AI访谈助手**。你只需设计访谈框架（主题、问题、类型），AI会以人格化的方式与受访者自然对话——不是机械宣读问卷，而是倾听、回应、追问、过渡，像真人访谈者一样。

**核心能力**：
- 三种访谈模式：结构化（标准化）、半结构化（兼顾深度与效率）、非结构化（自由探索）
- 智能追问：AI根据回答内容自动判断是否追问、追问几次、何时过渡到下一个话题
- 科技国风数字人：受访者端展示可交互的SVG数字人，表情随访谈阶段变化
- 多模态支持：图片识别、语音输入、语音合成（可选）
- 原生服务：兑换码激活后无需配置API密钥，开箱即用

**数据安全**：
- 研究者端、受访者端、后端服务三端分离
- 原生模式下API密钥仅存于后端，前端用户无法接触
- 本地部署，数据不上传第三方

## 适合谁

- 做质性/混合研究的社科研究者（社会学、教育学、心理学、传播学等）
- 需要大规模访谈但人力有限的调研项目
- 想让AI辅助访谈、但仍保留研究者设计权的团队
- 不想配置复杂AI接口、希望"激活即用"的用户

不适合谁：
- 只需要机械问卷投放（用问卷星更合适）
- 要求完全控制AI每句话内容（问灵的设计理念是"目标驱动"而非"脚本驱动"）
- 需要云端多团队协作（问灵目前是单体部署）

## 主要能做什么

### 1. 设计访谈框架

- 创建访谈项目：填写主题、描述、预设问题
- 选择访谈类型：结构化/半结构化/非结构化
- 设置访谈参数：追问次数上限、超时时间、AI温度
- 系统提示词模板：可选内置模板或自定义AI人格

### 2. 发布与邀请受访者

- 发布访谈后创建会话，获得**访问码**（如 `A1B2C3`）
- 将访问码发送给受访者（邮件、微信、短信等）
- 受访者无需注册，输入访问码即可开始访谈

### 3. AI智能访谈

- AI以**访谈者人格**与受访者对话：自然开场、倾听回应、灵活追问、温暖收尾
- **话题覆盖追踪**：后台实时记录每个预设目标的覆盖状态
- 三种模式的追问策略不同：
  - 结构化：严格按序，无追问
  - 半结构化：任意顺序，每话题≤N次追问
  - 非结构化：目标仅参考，自由探索≤M轮

### 4. 数字人交互（受访者端）

- **科技国风SVG数字人**：插画风格角色，淡蓝科技光效
- 表情切换：微笑、感兴趣、温暖、思考（随访谈阶段自动变化）
- 微动画：呼吸起伏、眨眼、头部轻晃
- 响应式：桌面端侧栏展示，移动端顶部横幅

### 5. 结果分析

- 对话流完整记录：每轮问答的时间戳、AI动作、覆盖目标
- 话题覆盖度可视化：预设目标完成比例
- AI生成访谈摘要：核心发现、关键洞察、情感态度、建议方向
- 导出功能：支持导出访谈记录为多种格式

## 快速上手三步

1. **启动系统**：运行 `start-all.bat`（Windows）或按下方命令分别启动三端
2. **研究者登录**：访问研究者端，用演示账号（admin / 123456）登录
3. **创建访谈**：新建访谈项目 → 添加问题 → 发布 → 创建会话 → 把访问码发给受访者

第一次用会提示你配置AI服务商或激活原生服务。最简单的方式是**兑换码激活原生服务**——无需任何API密钥配置，开箱即用。

## AI服务配置指南

问灵支持三种AI接入方式：

### 方式一：原生服务（推荐，无需配置API）

激活原生服务后，系统自动使用阿里云百炼（DashScope）作为AI后端：
- **兑换码激活**：在智能体设置页面输入兑换码，即刻可用
- **无需API密钥**：密钥由系统后端管理，前端用户完全接触不到
- **模型选择**：DeepSeek V4 Flash / DeepSeek V4 Pro / Kimi K2 等
- **多模态/语音**：原生服务已集成图片识别、语音输入、语音合成

### 方式二：预设模式（自备API密钥）

在智能体设置页面选择模型提供商，填写你的API密钥：
| 提供商 | 推荐模型 | 备注 |
|--------|---------|------|
| DeepSeek | DeepSeek V3 / R1 | 国内、极便宜 |
| Moonshot (Kimi) | Kimi K2 / Moonshot 128K | 长上下文擅长 |
| OpenAI | GPT-4o / GPT-4o-mini | 需海外资源 |
| Anthropic | Claude Sonnet 4 / Claude 3.5 | 需海外资源 |
| Google | Gemini 2.5 Flash / Pro | 需海外资源 |

### 方式三：进阶模式（自定义配置）

适合接入第三方兼容OpenAI格式的服务：
- 自定义API地址（URL）
- 自定义模型ID
- 支持深度思考、工具调用等高级参数

## 安装与启动

### Windows一键启动

双击 `start-all.bat` 即可启动后端 + 研究者端 + 受访者端。

### 手动启动

```bash
# 1. 启动后端
cd backend
cp .env.example .env
npm install
npm run seed   # 创建演示账号
npm start      # :3001

# 2. 启动研究者端
cd frontend-user
npm install
npm start      # :3000

# 3. 启动受访者端
cd frontend-respondent
npm install
npm start      # :3002
```

## 技术栈（开发者参考）

- **后端**：Node.js + Express + SQLite（轻量级数据库）
- **AI引擎**：支持多提供商 + 原生服务（阿里云百炼）
- **研究者端**：React 18 + React Router + Axios
- **受访者端**：React 18 + SVG数字人 + WebAudio
- **部署**：本地单体部署，数据存储于 `backend/data/`

目录结构：
```
wenling-ai-interviewer/
├── backend/                   # 后端服务 (:3001)
│   ├── src/
│   │   ├── controllers/       # API控制器
│   │   ├── models/            # 数据模型
│   │   ├── services/ai/       # AI引擎 + 多模态 + ASR + TTS
│   │   └── routes/            # API路由
│   └── data/                  # 数据库 + 上传文件
├── frontend-user/             # 研究者端 (:3000)
├── frontend-respondent/       # 受访者端 (:3002)
└── start-all.bat              # Windows一键启动脚本
```
